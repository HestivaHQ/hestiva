# Homepage About continuation link

Status: IMPLEMENTED

The homepage About section now includes a customer-facing **Learn more about Homent** continuation link to `/about`.

## Scope

- Keeps the existing homepage About headline, Homent Moment copy, and value cards unchanged.
- Adds a direct navigation path for visitors who want to continue into the full About page.
- Does not change business rules, service definitions, pricing, application boundaries, or HestivaOS integration.

## Rationale

The homepage About section previously introduced the brand story but ended without a continuation path. The link improves internal navigation and the customer journey without redesigning the section.
