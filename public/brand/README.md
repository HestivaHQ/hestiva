# Hestiva brand assets

This directory is the stable public location for approved Hestiva brand assets.

The following filenames are reserved for the final asset package:

- `logo.svg` — primary logo;
- `favicon.svg` — browser icon;
- `social-preview.jpg` — Open Graph and social preview image.

No placeholder assets are published. When approved files are supplied, add them here and set the
corresponding nullable paths in `src/lib/site.ts`.
